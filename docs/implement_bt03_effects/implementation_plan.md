# BT03 カード固有効果実装計画

## 目標
BT03で追加されたカード89枚のテキスト内容を解析し、ゲームシステム(`server/data/cards.json`および`server/game/Game.ts`)で正しく動作するように固有効果（Effects）を実装する。

## 実装方針

### 1. 共通キーワードによる基本効果の自動付与（フェーズ1）
スクリプト `server/scripts/apply_bt03_keywords.js` を作成し、カードの `keywords` または `text` をもとに、以下の基本的な `effects` オブジェクトを自動追加します。
- **[アタッカー]**: `ON_ATTACK` 時に自身へバフを付与する効果
- **[ディフェンダー]**: `PASSIVE` として相手ターンの攻撃対象になる処理（システム側に依存）
- **[貫通] (PENETRATION)**: `ON_ATTACK` 時に相手プレイヤーへダメージを与える効果
- **[パッシブ]**: 永続的なバフ効果など
- **[トリガー]**: `ON_DAMAGE_TRIGGER` 時のドロー機能や手札追加など

### 2. 固有・複雑な効果の手動実装（フェーズ2）
スクリプトによる自動付与が難しい、個別の条件判定や特殊なターゲット選択が必要なカード（例：特定属性の数に応じてパワーアップ、特定コストのカードをトラッシュから回収など）については、個別に `cards.json` の `effects` 配列を手動で修正します。
必要に応じて、`server/game/Game.ts` や `EffectResolver.ts` などのバックエンドロジックに新しいアクションタイプ（`ActionType`）や条件判定（`ConditionType`）を追加します。

### 3. 未実装・新規キーワードのシステム追加
BT03で初登場、またはこれまで未実装だった以下の機能について優先的にバックエンド(`server/game/Game.ts`等)へ実装します。
- **[防壁] の拡張**: 自身のレストに加え、手札コスト（`BOUHEKI_2`など）を要求するロジックの実装。
- **コスト付きアクティブ効果**: `[1] このユニットのパワーが対向ユニットより高いなら...` のように、指定コスト(リソース)を払って起動する汎用的な処理枠組み（済）
- **条件付き防御**: 特定のカードを手札からトラッシュすることで防御を代替・強化するシステム

### 4. Legend（L）カードの「フリップ（反転）」システム
BT03のLカード（BT03-018など）はリーダーレベル等の条件で「基本面」から「覚醒面」へ反転します。
- リーダーレベルの更新時、またはターン開始時にフィールドのLカードの条件をチェック。
- 反転時にパワー、テキスト、効果を切り替えるロジックを `Game.ts` に実装。

## 個別実装対象カード (SR/UR/L)
以下の高レアリティカードについて、固有のロジックが正常に動作するように `Game.ts` の拡張と `cards.json` の設定を行います。

### 1. 特殊なアクション・条件を伴うカード
- **BT03-039 (シンデレラ)**: 「トラッシュからコスト4のユニットを回収」
  - `ADD_FROM_DISCARD` に `COST_4` 条件の処理を追加。
- **BT03-060 (ヘルム)**: 「相手との手札枚数差分によるダメージ」
  - 新規アクション `DAMAGE_BY_HAND_DIFF` を追加。
- **BT03-076 (レオナ)**: 「ダメージゾーンのユニットと手札/フィールドの入れ替え」
  - 新規アクション `SWAP_WITH_DAMAGE` を実装。
- **BT03-079 (ベヒモス)**: 「トラッシュのアイテムをデッキ底に戻し、相手ユニットを除去」
  - 複数のカード選択（Selection）を伴う複合アクションの実装。
