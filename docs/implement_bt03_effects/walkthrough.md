# BT03 カード効果実装・検証記録

BT03の新しいゲームメカニクスおよび特定カードの効果について、実装と検証が全て完了しました。

## 実施した検証項目

### 1. Legendカードの反転検証
- **テストケース**: `BT03-018` を場に出し、リーダーレベルを 4 から 5 に上げる。
- **結果**: 期待通り `checkLegendFlipping` がトリガーされ、カードが `isAwakened` 状態に遷移、反転時効果（`ON_AWAKEN`）が実行されました。

### 2. コスト付き防壁の検証
- **テストケース**: 手札が2枚ある状態で `BT03-061` が防壁を発動。
- **結果**: 割り込みフェーズで手札2枚の選択（`PAY_BOUHEKI_COST`）が要求され、破棄後に正しく攻撃をブロックしました。

### 3. ベヒモス (BT03-079) の複合効果検証
- **テストケース**: 手札と捨て札からアイテムを複数枚（合計コスト8以上）デッキに戻し、相手の強力なユニットを破壊してドロー。
- **結果**: 
  1. `BEHEMOTH_STEP_1` (アイテム選択・デッキ戻し)
  2. `BEHEMOTH_STEP_2` (破壊対象選択・破壊・ドロー)
  この二段階の処理が、計算されたコスト予算内で正確に動作しました。

### 4. その他SRアクション
- **ヘルム**: 相手との手札枚数差に応じたダメージ計算が正確であることを確認。
- **レオナ**: ダメージゾーンのカードと場のカードを交換し、適切なセクションに移動することを確認。
