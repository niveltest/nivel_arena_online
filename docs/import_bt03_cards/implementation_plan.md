# BT03 カード実装計画

## 目標
公式サイトからブースターパック第3弾「アンブレイカブル」(BT03)のカード情報をスクレイピングし、ゲームシステム(`server/data/cards.json`)に統合する。

## User Review Required
> [!IMPORTANT]  
> 今回のタスクではカードの**基本データ（名前、コスト、パワー、属性、テキストなど）の抽出と登録**を主目的とします。  
> 複雑な固有効果（Active Abilitiesなど）の実装が必要な場合は、マスターデータ追加後に別タスクとして進行するか、このまま本タスクで実装を続けるかどうかの判断をお願いします。  
> 基本的なキーワード（[アタッカー]等）については可能な限りマッピングします。

## 提案する変更内容

### マスターデータの追加
#### [MODIFY] server/data/cards.json
- `bt03_raw.json` から `BT03-` で始まるカードリストを抽出し、既存のカードスキーマ（id, name, type, cost, power, text, keywords, imageUrl など）に合わせて末尾に追加します。
- 一時的スクリプトとして `server/scripts/merge_bt03.js` を作成し、マージを実行後に削除します。

## 検証計画
### 自動テスト
- `cd server && npm run dev` にてサーバーが正常に起動し、`cards.json` がエラーなく読み込まれることを確認します。
- 既存のテストスクリプトを使ってスキーマ・バリデーションエラーが発生しないか確認します。

### 手動検証
- ブラウザ機能を利用して `npm run dev:all` でアプリケーションを起動します。
- UIのカード一覧（またはデッキビルド画面）にて、BT03で検索し、カード画像や詳細情報が正しく表示されることを確認します。
