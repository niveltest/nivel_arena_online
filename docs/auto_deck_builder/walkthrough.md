# デッキ自動構築機能の実装完了

指定されたリーダーに基づいて自動的にデッキを構築する機能を `DeckBuilder` コンポーネントに追加しました。

## 主な変更点

1. **`DeckBuilder.tsx` への「自動構築」ボタンの追加**
   - サーバー保存ボタンの左隣に「自動構築」ボタンを設置しました。

2. **`handleAutoBuild` ロジックの実装**
   - リーダーの属性に合致するカード（または無属性カード）のみをプールから選出します。
   - **トリガーカードは8枚まで**、**同名カードは3枚まで**の制限を厳密に守ります。
   - ユニットの枚数が20〜25枚程度になるようにバランス調整を行います。
   - 合計がぴったり40枚になるようカードを追加し、残りはアイテムやスペルカードで埋めます。
   - カードプールが不足している（40枚に満たない）場合はエラーメッセージを表示します。

## 今後の利用方法について
デッキ構築画面でリーダーを選択した後、「自動構築」ボタンを押すだけで、ルールと相性に則ったデッキが40枚で生成され、そのままサーバーへ保存できるようになります。
